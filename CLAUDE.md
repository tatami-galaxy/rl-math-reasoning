## Project Overview

The project contains many folders. However you should only focus on the neural_ode folder : 

```
rl-math-reasoning/
├── neural_ode/             # Neural ODE analysis of LLM reasoning
    ├── expts               # Some tests and introductory experiments
    ├── hidden_states       # Neural ODE on LLM hidden states
    ├── text                # Neural ODE on LLM text output
        ├── latent_ode      # Model LLM reasoning trace data with latent ODE
```

At this point we are primarily interested in modeling LLM text reasoning traces in response to math problems. We are interested in modeling the traces with neural ODEs or other methods that enable us to learn a vector field governing the traces in some latent space.

We consider each trace to be made of a sequence of segments where the segment delimiters are newline or multiple newline characters for example. Each text segment is embedded into a latent space by some embedding method such as SONAR, Sentence-Transformer etc. Each trace is therefore interpreted as a trajectory in the vector field where each embedded segment is a point in the trajectory.  

Given a dataset of successful traces, that is, traces culminating in successful outcomes, we want to accurately learn a vector field corresponding to the traces. We want to then analyse the vector field. 

We want to find interesting properties of the field and map them to text in the training data, as well as test data from a similar distribution. Finally, during post training of LLMs with Reinforcement Learning, as well as during inference, we want to use the learned vector field to guide LLMs in "good" directions. The hypothesis is that this should help the LLM quickly learn "good" reasoning traces. 

---

## Active Research Focus

- SONAR embeddings. SONAR embeddings can be decoded back into text. This means we can potentially decode embeddings generated by the ODE model back to text for validation, reward / contraints during training etc.

- Validating latent ODE on DeepMath traces. After we train the latent ODE (or any other model) we need to be able to validate that it has learned a meaningful and useful vector field. 

- Guiding LLM reasoning traces during generation

- GRPO, PPO, etc. reward shaping using the vector field. We might also be interested in other embedding models with different properties for using the field as a scalar reward signal

## Glossary

| Term | Meaning |
|------|---------|
| trace | LLM text output in the thinking phase in response to a prompt |
| latent ODE | model fitted to trace trajectories |
| RL | Reinforcement Learning |
| GRPO | Group Relative Policy Optimization (RL algorithm) |
| PPO | Proximal Policy Optimzation (RL algorithm) |
| SONAR | Meta's sentence embedding model used for text-level trace embedding |
| DeepMath | DeepMath-103K math reasoning dataset |
